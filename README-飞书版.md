# 飞书版启动器 · 使用说明

给 `WeChat-Chat-Export-for-LLM` 加了飞书入口，**没有改动上游任何源码文件**。

---

## 一、四个入口，按序号来

| 双击这个 | 什么时候用 | 得到什么 |
|---|---|---|
| `1-首次安装.bat` | **只跑一次** | 建 `venv\`、装依赖、自检 |
| `2-启动飞书版.bat` | 日常用这个 | 导出窗口 + 左下角「飞书导入 →」按钮 + 菜单栏「飞书导入」 |
| `3-启动飞书配置.bat` | 只想配飞书 | 只开飞书配置面板，不开导出窗口 |
| `可选-安装语音识别.bat` | 想要语音转文字才用 | 装 ASR 依赖 + 下载模型，约 200 MB |

- 2 和 3 打开的是**同一块面板**，配置共用一份，改哪个都一样。
- **第 1 步忘了跑也没关系**：2 或 3 发现没有 `venv\` 会自动替你跑一遍第 1 步，装完继续启动。

---

## 二、首次准备（只做一次）

1. 双击 `2-启动飞书版.bat`（或先跑 `1-首次安装.bat`，效果一样）。
   - 第一次会自动装环境，约 1~3 分钟，取决于网络。
   - 装完会打印 `[OK] all modules importable`。
2. 面板里填三样东西，点「连接自检」。

> 前提：Windows 10/11 x64，微信 4.x 已登录并保持后台运行。

---

## 三、面板里配什么

### ① 飞书应用
- **服务域名**：国内版选「飞书」，用 larksuite.com 才选 Lark
- **App ID**：`cli_` 开头，开发者后台 → 凭证与基础信息
- **App Secret**：同上，输入时打码，用 DPAPI 加密存盘
- 页面底部写着**必开的两组权限**和**加文档协作者**那一步，照抄即可

### ② 多维表格
- **Base 链接 / Token**：把浏览器地址栏整条粘进来，点「解析」自动拆出
  `base_token`（`bascn` 开头）和 `table_id`（`tbl` 开头）
- **数据表**：连接自检成功后下拉框会自动填满现有表；留空则新建
- **新表命名**：默认 `微信记录_{YYYY-MM}`
- **分表策略**：1 万条以内单表；1-5 万按月；5 万以上按月+按会话

### ③ 导入策略
- **每批条数**：上限 200，别改大（飞书接口硬限制）
- **批间隔 / 重试**：撞限流就调到 500-800 ms
- **附件策略**：混合（图片内嵌 + 大文件云盘链接）是推荐档
- **内嵌上限**：默认 20 MB，超过走云盘不占 Base 配额
- **时间范围 / 演练模式**：第一次建议勾演练，先看不写

### ④ 运行
- **导出目录**：会自动猜（在本仓库 `exports\`、当前目录、用户目录里找 `chat_full_parsed.json`），也可手动选
- **扫描导出目录**：报条数、时间范围、附件数、要打几批
- **① 初始化表结构 / ② 开始导入**：调执行引擎（阶段二脚本，未就位时会明确报缺哪个）

## 四、配置文件在哪

```
%LOCALAPPDATA%\wechat-to-feishu\config.json
```

- `App Secret` 用 **Windows DPAPI** 加密存储，换机器/换用户解不开，需要重填
- 也可以点「导出 .env」生成老式的明文 `.env` 给别的脚本用（注意别发人）
- 点「从 .env 导入」可反向读回

## 六、常见问题

**Q：能不能直接用官方 EXE 加飞书功能？**
不能。EXE 是打包死的单文件，页面改不进去。所以走源码版注入，界面和 EXE 一模一样。

**Q：上游更新了怎么办？**
重新下源码，覆盖根目录那 5 个上游文件（`app.py`、`cli.py`、`exporter_core.py`、`preview.py`、`wechat_data_dirs.py`）即可，
`app_feishu.py` 不用改（它按控件位置找底部按钮条，不依赖变量名）。

**Q：自检报 91403？**
应用没被加为 Base 协作者。回飞书：Base 右上角 ⋯ → 添加文档协作者 → 搜**应用名称**（不是 App ID）→ 可编辑。改完直接重试，不用等。

**Q：自检报 99991672？**
权限没开或没发版。开发者后台勾 `bitable:app`，然后**创建版本 → 发布**，审核过了才生效。

**Q：Secret 忘了？**
开发者后台可以重置，重置后回来重填一次。

**Q：面板打不开 / 一闪就没？**
在仓库根目录开一个 CMD，跑：

```bat
venv\Scripts\python.exe app_feishu.py
```

这样有控制台，报错看得见。常见原因是 `venv\` 损坏 —— 删掉它，重跑 `1-首次安装.bat`。

**Q：装依赖卡住 / 报网络错误？**
`1-首次安装.bat` 会自动回退到清华镜像。仍然失败就手动：

```bat
venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```
